## Decisions
- **Templates run in the plugin, not in the host:** `html/template` cannot be stopped from outside. A template like `{{range 2000000000}}` would have blocked a server thread, while inside the sandbox it hits the call's time limit.
- **SSE instead of WebSocket:** updates go one way; plain HTTP with the session cookie, no new protocol, and it works behind proxies.
  - The stream starts a moment after the page has loaded.
  - The session is re-checked on each heartbeat without counting as activity.
- **Presence uses heartbeats:** the editor sends one every 30 s, stale after 75 s. `expected_modified` stays the hard check against overwriting.
- **The live preview reuses the existing preview:** it autosaves and shows `?preview` in a frame. It marks the frame (`gp_live_preview`), so customizer drafts stay in the customizer.
- **PayPal records only after PayPal confirmed the message:** the WordPress plugin stored nothing; the older plugin stored even unconfirmed messages. Imported unconfirmed donations are marked.
- **Akismet does not get the browser behavior script:** GoPress has its own spam trap, and the script records typing and mouse movement.
- **The bundled plugins are approved like uploads:** shipping them in the binary does not grant permissions.

## Security review
An independent review agent attacked:
- the host additions;
- the live channel: event leaks across users, capabilities and topics, revoked sessions, CSRF, DoS, XSS in toasts;
- the three plugins: XSS through gallery data, gallery rights, IPN forgery and replay, data minimization, the Akismet key, fail-open behavior;
- the CLI and the build.

It found no Critical or High issues: no sandbox escape, no script in the admin origin, no event leak across capabilities or plugins, no CSRF and no IPN forgery. Every finding below was fixed with a regression test (`TestM4ReviewFindings`, `TestLiveTopicsRechecked`, admin plugin tests, plugin module tests).

While fixing them, a test found two more problems in the WASM runtime's defaults:
- **The clock:** wazero gives modules a fixed clock (2022-01-01). Dates of donations and galleries, the "last 12 months" sum and Akismet's monthly counts were wrong.
- **Randomness:** wazero gives modules a fixed random seed, so `crypto/rand` in a fresh instance always returned the same bytes. That would be predictable tokens in any plugin that makes them.

Both now come from the system, checked by tests that failed without the fix.

| Finding | Severity | Fix |
|---|---|---|
| Live topics were authorized only when the stream opened; a user demoted while connected kept getting the post's save and presence events | Low | Topics re-checked on every heartbeat; the stream ends when one is no longer allowed |
| `comment_pre_save` failed open when the check itself failed, timed out, was busy or paused, so a comment flood could get spam past Akismet | Low | Manifest `comment_check_failure: "hold"` (Akismet sets it): such comments are held |
| PayPal: a resent "Completed" undid a refund; a refund arriving before its payment was lost | Low | Refunds are final (only a cancelled reversal restores); early refunds are kept and applied |
| PayPal: long donor names made the mail subject too long, so no mail was sent (errors ignored) | Low | Subject without the name, the name is in the body; mail errors logged |
| Galleries over 200 images rendered empty (the host describes 200 ids a call) | Low | `GetMedia` asks in chunks of 200 (PDK), the fake host has the same limit |
| Any `edit_posts` user could create galleries without limit (storage quota) | Low | Contributors only pick galleries; at most 200 per user and 2000 in total |
| Request errors returned the URL with its query to the plugin | Info | Only the underlying error is returned |
| A database error during the heartbeat looked like a logout | Info | The stream closes and the browser reconnects |
| Plugin page events were measured before JSON escaping and could be dropped silently | Info | Measured as sent; too large is an error |
| A table action named `saved` reached `HandleSubmit` | Info | `saved` is reserved for the settings check |
| Attachments in the trash or private ones were described to plugins | Info | Left out |
| PayPal accepted a match on `business` (from the button form) as the receiving account | Info | Only `receiver_email`/`receiver_id` |
| Akismet did not report spam → pending as ham | Info | Every move out of spam (except to trash) is reported |
| Concurrent duplicate IPN deliveries can mail twice; charsets beyond UTF-8 and windows-1252 are not converted; Akismet's counters can lose a count under concurrency | Info | Accepted (rare, harmless) |
