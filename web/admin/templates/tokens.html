Access Tokens

Access tokens let AI agents such as Claude Code write posts for you through the MCP interface. An agent can only do what the token's scopes allow, never more than your role, and only with your own posts. Content from agents is always filtered (no scripts or embedded code).

Claude Code

Add the server for your user (the token is stored in your Claude Code user settings, not in a project):

claude mcp add --transport http --scope user gopress {{$.Endpoint}} \
  --header "Authorization: Bearer {{.Token}}"

Or share the server with a project in .mcp.json and keep the token in the environment variable GOPRESS_TOKEN. Never commit the token.

{
  "mcpServers": {
    "gopress": {
      "type": "http",
      "url": "{{$.Endpoint}}",
      "headers": { "Authorization": "Bearer ${GOPRESS_TOKEN}" }
    }
  }
}
